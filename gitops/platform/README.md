Exemples prevus :

- namespaces ;
- Argo CD ;
- Gateway API / NGINX Gateway Fabric ;
- NetworkPolicies communes ;
- External Secrets Operator ;
- Kyverno ;
- observabilite.

Chaque composant doit rester dans un sous-repertoire dedie pour eviter de
melanger les responsabilites.
